## Phase 0 — Board API Surface & Recon

### Board API Contract
- **`GET /api/board`** (`web-ui/app/api/board/route.ts:11-20`): Returns `{ items: BoardItem[] }`, combining persisted items from `BoardStore` (`seedBoardIfEmpty`) with non-persisted thread-backed and checkpoint-ghost items via `mergeThreadsIntoBoard`.
- **`POST /api/board`** (`web-ui/app/api/board/route.ts:22-40`): Calls `fileBoardItem(...)` which forces `status: "queued"`.
  - Required fields (`boardStore.ts:168-181`): `title` (non-empty string), `brief` (non-empty string).
  - Defaulted / optional fields: `author` (defaults to `"Owner"`, must be `"Owner"`), `source` (defaults to `"manual"`, must be `"manual" | "assistant"`), `dependencies` (`string[]`, default `[]`), `key` (optional, auto-generated as `#${items.length + 1}`), `threadLink`, `sprint`.
  - Returns HTTP `201` `{ item: BoardItem }`, or HTTP `400` `{ error }`.
- **`PATCH /api/board`** (`web-ui/app/api/board/route.ts:42-55`): `{ id, ...UpdateBoardItemInput }` -> `200 { item }`.
- **`GET /api/board/control`** / **`POST /api/board/control`** (`web-ui/app/api/board/control/route.ts:7-65`): Reads/mutates board control record (`action: "start" | "pause" | "stop"`, optional `drainBudget: number | null`, `threadId`, `taskId`).
- **`GET /api/board/drain`** / **`POST /api/board/drain`** (`web-ui/app/api/board/drain/route.ts:14-117`): Returns last drain report or runs `BoardOrchestrator.drain()` bounded by `{ maxItems, maxDurationMs, dryRun }`. Returns `409` if control state is not `"running"`.
