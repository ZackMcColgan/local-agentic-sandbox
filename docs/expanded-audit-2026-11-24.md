**Top 5 Cross-Cutting Risks at `dda360292f`:**

1. **Self-deploy self-termination & Kubernetes `RollingUpdate` split-brain (`SYS-1`, `DUR-2`, `HO-1`):** `web-ui` runs as `replicas: 1` with default `RollingUpdate` over a `ReadWriteOnce` PVC and executes `deploy-cluster.js` / `kubectl set image` inside the pod being replaced — killing the deployer pod before S4 verification, auto-rollback, or deploy suspension can run while two pods concurrently run `SchedulerDaemon` and orphan reconcilers against the same PVC.
2. **Unauthenticated MCP `/mcp` + wildcard CORS + shared `/workspace/.agent/` state (`MCP-1`, `MCP-2`, `MCP-3`, `N-S1`):** `mcp-server` (`POST /mcp`, `GET /files`) and `browser-mcp` (`POST /mcp`) have zero auth and disabled DNS-rebinding protection; `mcp-server` enables wildcard `cors()`, runs arbitrary `/bin/sh -c`, shares `/workspace` (including `/workspace/.agent/*` threads/SQLite/settings) with `web-ui` under matching GIDs, and has `:443`/`:53` egress. `POST /api/deploy` (`deployBuild`) also permits unauthenticated SSRF via unvalidated `dryRunUrl`.
3. **Pooled MCP transport torn down on every turn & `GET /mcp` 404 eviction race (`N-R1`, `MCP-4`):** `connectMcpClient()` wraps `client.close()` as a no-op but leaves `session.transport` unwrapped; `roundLoop.ts:3165-3172` calls `session.transport.close()` in `finally`, aborting the shared `StreamableHTTPClientTransport` for overlapping/subsequent turns, while `GET /mcp` returns Express `404` instead of `405`, firing `onerror` pool eviction.
4. **Live single-slot preemption & thread/daemon truth failures (`UI-H3`, `UI-H1`, `UI-H7`, `SYS-2`, `SYS-3`):** On live prod (`http://192.168.50.254`), an interactive `P0_OWNER` turn sat at `Queued (position 1)...` for `>4 min` behind active board job `#58` while displaying fake `REASONING Thinking...` and `New thread · RUNNING`; `28` threads report `status: "running"` (`27` dead zombies); `inAppSupervisor` repeatedly spawns `Auto-resume attempt 1/2 for job job-auto-1.` every few minutes; `scheduler-health` reports `degraded` (`lastTick` >1h stale) while `#58` runs; and `host-bridge` executes synchronously (`POST /execute`) without process-tree cleanup on pod disconnect.
5. **Unbuilt/unwired Stage 2–4 handover machinery & host-bridge test blind spot (`HO-2`, `HO-3`, `HO-4`, `T-1`, `T-2`):** Stage 3 merge execution (`gh pr merge`) is unbuilt and `finishVerificationClean` defaults `false`; `flowMonitor.issueThread` creates un-dispatched threads and `BoardOrchestrator` marks PRs `"done"` on the first tick; `prodEqualsDevelop: true` is hardcoded; `host-bridge` has `0` workspace tests; and running `web-ui` `npm run test` mutates tracked `docs/architecture.svg` and fails 4 suites on Windows due to open SQLite `EBUSY` handles.

### Critical

#### `N-R1` [Critical / Runtime] — Pooled MCP teardown closes unwrapped `StreamableHTTPClientTransport`, aborting shared sessions across turns (plus pool-reset & single-error eviction races)

- **Evidence:** `web-ui/lib/chat/mcpClients.ts:105-129,181-191,211-256`; `web-ui/lib/chat/roundLoop.ts:704-711,3165-3172`; `node_modules/@modelcontextprotocol/sdk/dist/esm/client/streamableHttp.js:294-301,318`.
- **Failure Mode:** `connectMcpClient()` wraps `rawClient.close()` as a no-op (`mcpClients.ts:112-115`) so pooled handles stay alive, **but leaves `entry.session.transport` unwrapped** (`:232`). Both cleanup blocks in `roundLoop.ts:704-711,3165-3172` call `await session.transport.close()`, which unconditionally runs `this._abortController?.abort()` and `this.onclose?.()`, destroying pooling on every turn and aborting overlapping turns sharing the session. Additionally, `connectMcpClient()` has no epoch check across `await openMcpSession(...)` if `resetMcpClientPool()` runs mid-connect, and a single `callTool` error (`:120-122`) closes raw handles under concurrent callers.
- **Fix:** Proxy `session.transport.close()` as a no-op for pooled sessions (or introduce `releaseMcpSession()`), add a pool epoch guard across `openMcpSession`, and ref-count active callers before closing raw handles.

#### `N-S1` [Critical / Security] — Unauthenticated SSRF in `POST /api/deploy` (`deployBuild`) via unvalidated `dryRunUrl` + Origin-less CSRF acceptance (plus latent shell injection in `DeployPipeline`)

- **Evidence:** `web-ui/app/api/deploy/route.ts:33-49,57-62,73-125`; `web-ui/lib/deploy/deployPipeline.ts:154,181-183,246,316-317`.
- **Failure Mode:** `isSameOriginRequest(req)` (`deploy/route.ts:40-41`) returns `true` whenever both `Origin` and `Referer` are omitted. In `action === "deployBuild"`, `body.dryRunUrl` is assigned directly to `deploymentUrl` (`:104-105`) with zero URL/host/IP validation and passed to `fetch(deploymentUrl, ...)` (`:118-120`), returning HTTP status and connection errors to any unauthenticated network caller targeting `169.254.169.254`, `127.0.0.1`, or internal services. Separately, `DeployPipeline.deployBuildTask()` (`deployPipeline.ts:181-183`) interpolates `input.workspaceDir` into `execAsync` (`docker build -t ${imageTag} "${input.workspaceDir}"`) and probes unvalidated `hostAddress`.
- **Fix:** Allowlist `dryRunUrl` strictly to preconfigured preview origins (or validate with `validateHostAddress` + block loopback/RFC1918/link-local), reject missing-`Origin` state-changing requests (or require a server CSRF token), and replace `execAsync` string interpolation in `DeployPipeline` with `execFile`/`spawn` (`shell: false`).

### High

#### `N-S2` [High / Security] — Opt-in host file restriction bypassed by `host_run_powershell` without `cwd` and missing host-side canonical symlink resolution

- **Evidence:** `web-ui/lib/hostPathRestriction.ts:18-55,66-83`; `web-ui/lib/hostMode.ts:389-392`.
- **Failure Mode:** `collectPathArguments()` only inspects `args.path`, `args.paths`, and `args.cwd` for `host_run_powershell`. Omitting `cwd` (or referencing external paths inside `command`) returns `{ allowed: true }`. #### `N-S3` [High / Security] — Unconfined arbitrary disk file reads via `plannedFiles` (`targetFile`) in `GET /api/threads` and `GET /api/threads/[id]`

- **Evidence:** `web-ui/app/api/threads/route.ts:395-406`; `web-ui/app/api/threads/[id]/route.ts:121-142`.

#### `N-S4` [High / Security] — Symlink escape in `GET /api/explorer/read` via lexical-only `confineExplorerPath`

- **Evidence:** `web-ui/lib/explorer/explorerFs.ts:63-85,164-199`; `web-ui/app/api/explorer/read/route.ts:8-15`.

#### `N-R2` [High / Runtime] — `JobQueue.drain()` couples per-turn settlement to global queue idle epoch

#### `N-R3` [High / Runtime] — Per-chunk `abort` listener leak in LLM stream readers and `<think>` tag leakage in `LlamaCppProvider.generate()`

#### `N-R4` [High / Runtime] — Host PowerShell wrapper swallows `NativeCommandError`, skipping trailing commands and exiting `0`

- **Evidence:** `host-bridge/powershellRunner.ts:3-33`.
- **Failure Mode:** `POWERSHELL_WRAPPER_SCRIPT` runs `& ([scriptblock]::Create($__hostPsCmd))` inside a single `try/catch` whose `catch` ignores `NativeCommandError` without setting `$__hostPsHadTerminatingError`. #### `N-R5` [High / Runtime] — Opt-in host file restriction breaks `host_git_add` relative `paths`

### C.2 Ranked Findings (`MCP-1`–`MCP-10`)

#### `MCP-1` [Critical] — Unauthenticated `/mcp` and `/files`, wildcard CORS (`*`), and disabled DNS rebinding protection

- **Evidence:** `mcp-server/src/index.ts:12-14,94-129,146-176`; `browser-mcp/src/index.ts:6-7,33-63`; `node_modules/@modelcontextprotocol/sdk/dist/esm/server/webStandardStreamableHttp.js:78-80,141-165`; `web-ui/app/api/chat/route.ts:114-142`; `web-ui/app/api/files/route.ts:88-107,223-267`.
