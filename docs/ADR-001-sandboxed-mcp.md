# ADR-001: Sandboxed Model Context Protocol (MCP) Execution Boundary

## Status
Accepted

## Context
Autonomous AI agents that execute code require access to runtime environments (interpreters, shells, package managers). In standard local or enterprise configurations, running arbitrary code generated by an LLM on the developer's host machine or on an unisolated server creates critical attack vectors:
1. Arbitrary code execution (RCE) with host privileges.
2. File system tampering and credential theft (reading `~/.ssh`, `~/.aws`, `.env`).
3. Covert data exfiltration and command-and-control communication over the public internet.

To mitigate these risks while preserving high-speed local inference and tool-calling capabilities, `local-agentic-sandbox` implements an air-gapped, zero-trust container topology.

## Decision
We decouple the platform into three isolated tiers:

1. **Air-Gapped Local Inference Engine (Ollama)**
   - Runs locally on the isolated `ai-mesh` internal network (`internal: true`).
   - Does not have internet access, preventing leakage of private code or conversation prompts.

2. **Hardened Execution Boundary (MCP Server)**
   - Standardized on the Model Context Protocol (MCP) using Server-Sent Events (SSE).
   - Enforces an unprivileged execution user (`uid: 10001:10001`).
   - Runs with a read-only root filesystem (`read_only: true`).
   - Drops all Linux capabilities (`cap_drop: ALL`, `no-new-privileges: true`).
   - Restricts writable disk space to an ephemeral, in-memory `tmpfs` mounted at `/tmp` (`size=64m,noexec,nosuid`).
   - Completely isolated on `ai-mesh` with zero internet egress.

3. **Agent Orchestrator & Web UI (Next.js 15)**
   - Acts as the dual-homed bridge between the user's browser (via `egress-mesh`) and the internal execution environment (`ai-mesh`).
   - Exposes an audit trail of every MCP tool invocation, parameter payload, execution duration, and attestation output.

## Consequences

### Positive
- **Guaranteed Isolation**: Compromised code running in the Python execution tool cannot modify system files, install kernel modules, escalate privileges, or communicate outside the Docker network.
- **Air-Gapped Privacy**: Sensitive data processed by the LLM never leaves the local machine.
- **Interoperability**: Standardizing on the official `@modelcontextprotocol/sdk` allows seamless expansion of tools and future client compatibility.
- **Observable Governance**: The Web UI displays live attestation and security gauges, giving developers confidence in the execution boundary.

### Considerations
- Dependencies executed by scripts must be pre-baked into the `mcp-server` image since dynamic network downloads (e.g., `pip install`) are blocked by the air-gap policy.
- Memory-heavy tasks are constrained by the 1024MB container memory limit and 64MB `/tmp` buffer.
